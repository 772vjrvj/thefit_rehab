# Laravel 개발을 위한 PHP 환경 구성 가이드 (Windows)

  1. PHP 다운로드 및 압축 해제
      1-1. PHP 공식 다운로드 페이지(https://www.php.net/downloads.php)에 접속합니다.
      1-2. Current Stable PHP 섹션에서 Windows downloads를 클릭합니다.
      1-3. VS17 x64 Thread Safe 항목에서 Zip 파일을 다운로드합니다.
      1-4. 다운로드한 압축 파일을 C:\php\php-8.4.13-TS 경로에 압축 해제합니다.

  2. 환경 변수(Path) 설정 방법
    2-1. 파일 탐색기에서 내 PC를 우클릭하고 속성을 클릭합니다.
    2-2. 관련 설정에서 고급 시스템 설정을 클릭합니다.
    2-3. 시스템 속성 창에서 환경 변수 버튼을 클릭합니다.
    2-4. 아래쪽 시스템 변수 영역에서 Path 항목을 찾아 선택하고 편집을 클릭합니다.
    2-5. 새로 만들기 버튼을 클릭하고, 실제 PHP가 설치된 경로를 정확히 추가합니다: C:\php\php-8.4.13-TS
  ※ Java(JDK)와의 차이점 (중요)
  Java는 실행 파일이 bin 디렉토리 안에 모여있지만, Windows용 PHP는 압축을 푼 최상위 폴더에 핵심 실행 파일(php.exe)이 바로 존재합니다. 따라서 bin 경로를 추가할 필요 없이 PHP 최상위 폴더 경로 자체를 등록해야 합니다.

  3. 변경 사항 적용 및 검증
    환경 변수 등록 후, 시스템에 정상적으로 반영되었는지 확인하기 위해 새로운 명령 프롬프트(CMD) 또는 터미널을 열고 아래 검증 과정을 진행합니다.

    3-1. PHP 버전 체크
      터미널에 php -v 또는 php --version 명령어를 입력하여 환경 변수가 올바르게 잡혔는지 확인합니다.
      C:\Users\772vj>php -v
        PHP 8.4.13 (cli) (built: Feb 10 2026 23:14:15) (TS Visual C++ 2022 x64)
        Copyright (c) The PHP Group
        Zend Engine v4.4.13, Copyright (c) Zend Technologies

    3-2. 헬로 월드(Hello World) 한 줄 실행 검증
      PHP CLI(Command Line Interface)를 사용하여 정상 작동 여부를 최종 테스트합니다.
      C:\Users\772vj>php -r "echo 'Hello World';"
        Hello World

  4. Composer 설치 및 검증
    라라벨의 다양한 라이브러리와 패키지를 관리하기 위해 PHP의 핵심 의존성 관리 도구인 Composer를 설치합니다. (Java의 Maven/Gradle과 같은 역할)

    4-1. Composer 설치 방법 (Windows)
      4-1-1. **다운로드 페이지 접속:** 공식 웹사이트 URL(https://getcomposer.org/download/)로 이동합니다.
      4-1-2. **설치 파일 다운로드:** 페이지 상단의 **"Composer-Setup.exe"** 링크를 클릭하여 실행 파일을 다운로드합니다.
      4-1-3. **설치 프로그램 실행:**
          * **Developer Mode:** 체크 안 함 (기본값 유지)
          * **Select Installation Option:** 모든 사용자용 설치(Install for all users) 권장

      4-1-4. **PHP 경로 지정 (중요):** 설치 과정에서 컴퓨터에 설치된 `php.exe` 경로를 자동으로 탐색합니다. 앞서 설정한 경로(`C:\php\php-8.4.13-TS\php.exe`)가 올바르게 지정되었는지 확인하고 Next를 누릅니다.
      4-1-5. **프록시 서버 설정:**
        * **Use a proxy server to connect to the internet:** 체크 안 함
      4-1-6. **설치 완료:** 이후 Next 및 Install을 눌러 설치를 마무리합니다.

    4-2. Composer 설치 완료 검증
      환경 변수와 프로그램이 전역으로 정상 등록되었는지 확인하기 위해 **새로운 명령 프롬프트(CMD)**를 열고 아래 과정을 진행합니다.

      4-2-1. **버전 및 상태 체크:**
        터미널에 대문자 `V`를 사용하여 `composer -V` 또는 `composer --version`을 입력합니다.
        C:\Users\772vj>composer -V
        Composer version 2.8.12 2025-09-19 13:41:59

      4-2-2. **작동 테스트:**
        터미널에 `composer`를 입력하고 엔터를 누르면, Composer 로고 텍스트와 함께 사용할 수 있는 명령어 목록(help)이 화면에 정상적으로 출력되는지 확인합니다.

  5. 라라벨 프로젝트 생성 및 초기 Git 설정
    인프라 세팅 완료 후, IntelliJ 설정(.idea) 및 Git 저장소 상태를 유지하면서 현재 폴더에 라라벨 프로젝트를 안전하게 이식하는 과정입니다.

    5-1. 임시 폴더를 통한 라라벨 다운로드
      현재 작업 폴더(E:\git\thefit_rehab)가 비어있지 않으면(예: .idea, .git 존재) 설치가 거부되므로, 임시 폴더에 프로젝트를 생성한 뒤 이동시키는 방식을 사용합니다.

      5-1-1. 터미널에서 현재 작업 디렉토리 위치를 확인합니다.
      5-1-2. 아래 명령어를 입력하여 임시 폴더(`temp_laravel`)에 최신 라라벨 프로젝트를 다운로드합니다.

        composer create-project laravel/laravel temp_laravel

        # 일반 파일 및 폴더 이동 (덮어쓰기 강제) -> 상위 폴더로 이동
        Move-Item -Path .\temp_laravel\* -Destination .\ -Force

        # 점(.)으로 시작하는 숨김 파일 및 환경 설정 파일 이동 (.env, .gitignore 등)
        Move-Item -Path .\temp_laravel\.* -Destination .\ -Force

        # 비어있는 임시 폴더 삭제
        Remove-Item -Recurse -Force .\temp_laravel

        * **주의 사항:** 이동 시 `.env`와 같은 핵심 숨김 파일이 누락되지 않도록 전체 선택(Ctrl+A) 후 누락 없이 상위 폴더로 이동되었는지 확인합니다.

    5-2. IntelliJ 버전 관리(VCS) 및 .gitignore 최적화
        로컬 개발 환경 설정(`.env`) 및 IntelliJ 개인 설정(`.idea`)이 Git 원격 저장소에 올라가지 않도록 필터링을 걸어줍니다.
        add to VCS

    5-3. 프로젝트 최상위에 생성된 **`.gitignore`** 파일을 엽니다.

    5-4. 파일의 가장 하단에 IntelliJ 설정 폴더를 제외하는 옵션을 추가하고 저장합니다.
        ```text
        .idea/

  6. 서버 실행
    6-1. key생성
      환경 변수(.env) 파일이 정상 위치에 있는지 확인한 후 아래 명령어를 입력합니다.
      php artisan key:generate

    6-2. 라라벨 내장 웹 서버를 실행합니다.
      ```bash
      php artisan serve

Step 1. 정적 파일(CSS, JS, 이미지 등) 옮기기
템플릿 폴더 안에 있는 파일 중 웹사이트의 디자인과 뼈대를 담당하는 폴더들을 라라벨의 public 폴더로 복사합니다.

템플릿 폴더에서 아래 폴더들을 선택하여 복사(Ctrl + C)합니다.

css/

js/

img/ (또는 images/)

lib/ 또는 scss/ (만약 폴더가 존재한다면 함께 선택)

라라벨 프로젝트 폴더의 public/ 폴더 안으로 이동해서 붙여넣기(Ctrl + V) 합니다.

확인: E:\git\thefit_rehab\public\css, E:\git\thefit_rehab\public\img 형태로 폴더들이 잘 들어갔는지 확인해 주세요.






Step 2. 메인 HTML 코드를 라라벨로 가져오기
이제 템플릿의 메인 화면인 index.html을 라라벨의 뷰(View) 파일로 이식하겠습니다.

템플릿 폴더에 있는 index.html 파일을 코드 에디터(IntelliJ 등)로 열고, 전체 내용(Ctrl + A)을 복사(Ctrl + C)합니다.

라라벨 프로젝트의 resources/views/ 폴더로 이동합니다.

그 안에 이미 만들어져 있는 welcome.blade.php 파일을 엽니다.

기존에 있던 라라벨 기본 코드를 전부 지우고(비우기), 아까 복사한 index.html 내용을 그대로 붙여넣기(Ctrl + V) 한 뒤 저장합니다.
